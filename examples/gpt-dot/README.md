# GPT Dot Example: Persistent Planning Assistant

A lightweight persistent assistant backed by OpenAI-compatible LLM endpoints.

## Characteristics
- **Provider**: `gpt-dotz`
- **Governance**: Provider-managed (Strict security boundary: NO silent inheritance of filesystem or shell execution tools)
- **Lifecycle**: Persistent conversation, task assignment, and steering
- **Model**: Configured via Hermes model provider or `OPENAI_API_KEY`

## Usage
1. Open Hermes Desktop ▸ **DOTZ** ▸ **+ New Dot**.
2. Select **GPT Dot**.
3. Provide your planning mission statement.
4. Interact via the conversation and task steering composer.
